# 💬 Example prompts — qonto-project-pnl

Invoke with `/qonto-project-pnl <your request>` — or just ask in plain language: the skill's description triggers it automatically.

## Getting started

- "Is project Aurora actually profitable?"
- "Build the per-project P&L and update my Finance database in Notion."

## Going further

- "What's the real margin on project Aurora — cashed revenue vs attributed costs?"
- "Which project is losing money right now? Rank them by margin."
- "Show me the label-to-project mapping before computing anything — I want to correct it."
- "What's my monthly burn per project, on a 3-month rolling basis?"
- "Which project invoices are overdue, and which costs look unusual this month?"
- "Build the P&L without touching Notion — tables and an HTML dashboard only."

## Chain it

- "Now project when each budget runs out with qonto-project-burn."
- "Chase the overdue invoices you flagged with qonto-invoice-chaser."
- "Roll these project margins up into the monthly picture with qonto-monthly-close."

> ⚠️ The Notion database is only created or updated after a write preview and your explicit consent — always refreshed in place, never duplicated.
