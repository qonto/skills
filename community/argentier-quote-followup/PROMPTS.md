# Example prompts: argentier-quote-followup

Invoke with `/argentier-quote-followup` or ask in plain language.

## En français
- "Quels devis relancer cette semaine ?"
- "Combien de chiffre d'affaires dort dans mes devis en attente ?"
- "Quel est mon vrai taux de signature ?"

## In English
- "Which quotes should I follow up this week?"
- "What is my quote conversion rate?"

## Chain it
- Then: "Fais une version SMS plus courte pour les particuliers."
- If installed, run argentier-cash-forecast with the quotes expected to sign.
