qonto-ceo-cockpit

« My Société » — le cockpit du dirigeant, généré à la volée depuis le compte Qonto.

📖 100 % lecture seule🎛 Recalcul live sans MCP 👁 Mode présentation📄 PR-ready

🎯 Le pitch

Ta banque te montre une liste de lignes. Pour voir ta boîte — d'où vient l'argent, où il va, où tu seras dans 3 mois — il faut un tableur… ou 3 semaines d'expert-comptable. Le skill fait ça en un prompt : « montre-moi ma boîte » → un dashboard HTML interactif et autoportant :

1

Vue des flux

Sources de revenus → société → postes de dépenses (type Sankey), rubans ∝ montants, bascule mois/année, tooltips.

2

Cartes & prévisionnel 3 mois

Mois / année / prévisionnel par poste + KPI : solde consolidé, résultat du mois, coffre fiscal, 3 mois — 🟢 réel / 🟡 estimé.

3

Hypothèses TJM live

TJM détecté sur les factures × jours facturables : sliders, recalcul instantané dans la page — zéro rappel du MCP.

4

Masquage 👁

Un clic masque un poste sensible et recalcule les totaux — pour présenter sans tout montrer (rendez-vous banquier).

⚙️ Fonctionnement global

Ce qui rend le skill robuste sur données sales

  • Pas de labels ? Regroupement par contrepartie normalisée, annoncé clairement — et bucket « à catégoriser » explicite avec son nombre de transactions, jamais dilué en douce
  • Virements internes neutralisés : les mouvements entre comptes de l'organisation ne sont ni des revenus ni des dépenses ; celui vers le sous-compte impôts alimente la jauge du coffre
  • Pas de facturation à la journée ? Le panneau TJM est omis, avec la raison — le reste du cockpit est complet
  • Pas de sous-compte impôts ? Jauge masquée, tout le reste fonctionne
  • Compte vide ou récent ? Cockpit en état honnête : tags 🟡, avertissement, jamais de chiffre inventé
  • Pagination ≤ 50 partout, fenêtres de 3 mois · société non française → libellés fiscaux neutres, zéro règle locale inventée

🏗 Schéma fonctionnel

🔒

100 % lecture seule : aucune écriture, aucun virement, rien à approuver. Le livrable est un fichier HTML local et autoportant — les données ne quittent pas la machine, aucun code externe ne se charge. Le masquage 👁 est une commodité de présentation (les données restent dans la source du fichier) ; pour partager, le skill régénère un export où les postes masqués sont réellement exclus.

🛡 Garde-fous

  • Skill 100 % lecture : aucun outil d'écriture, aucun virement, rien à approuver — dit clairement si on lui demande
  • Masquage 👁 = présentation, pas sécurité : jamais présenté comme un document expurgé ; export réellement exclu proposé pour le partage
  • Prévisionnel et hypothèses = estimations 🟡, pas de la comptabilité — validation expert-comptable recommandée
  • IBAN masqués (4 derniers chiffres) · pagination ≤ 50 partout · jamais de catégorie, règle fiscale ou chiffre inventés
